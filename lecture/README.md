해군 소령(O-4) 대상 3~4시간 특강용 HTML 슬라이드 강의자료입니다.
단일 파일(`index.html`)로 완결되어 있으며 외부 의존성이 없습니다.

**👉 [강의자료 열기](https://edu-data.github.io/DRM6/lecture/)**

각 실습의 산출물이 마지막 슬라이드에서 회수되도록 설계되었습니다.

## 사례연구

본 저장소의 **DRM6**(일상재구성법 기반 시간대별 경험 조사)를 Part 05의 사례로 사용합니다.
회상 편향을 설계로 차단한 방식, 7가지 설계 결정과 각각이 차단하는 오차,
2개 시트로 나뉜 데이터 스키마가 만드는 3수준 위계 구조,
그리고 동일 설계를 함정 승조원 조사로 옮길 때의 고려사항을 다룹니다.

## PowerPoint 판

같은 내용을 `.pptx` 로도 만들 수 있습니다. `pptx/` 의 생성기가 이 HTML 을 읽어
63장짜리 PowerPoint 를 만들며, 발표자 노트도 함께 넘어갑니다.

```bash
cd pptx && pip install python-pptx && python build_pptx.py
```

바로 쓸 수 있는 결과물: [`pptx/조사연구방법과_논문작성법.pptx`](pptx/조사연구방법과_논문작성법.pptx)

## 조작

| 키 | 동작 |
|----|------|
| `→` `Space` `PgDn` | 다음 슬라이드 |
| `←` `PgUp` | 이전 슬라이드 |
| `Home` / `End` | 처음 / 마지막 |
| `O` | 목차 열기 (`Esc`로 닫기) |
| `N` | 발표자 노트 토글 |
| `F` | 전체화면 |

- 하단 진행바를 클릭하면 해당 지점으로 이동합니다. 눈금은 구간 경계입니다.
- 주소의 `#s31` 형태 해시로 특정 슬라이드를 직접 열거나 공유할 수 있습니다.
- **인쇄** 버튼(또는 `Ctrl/Cmd+P`)으로 슬라이드당 1페이지의 배포용 유인물을 만들 수 있습니다.
  인쇄물에는 발표자 노트가 함께 출력됩니다.

## 기술 사항

- 단일 HTML 파일. 외부 스크립트·폰트·이미지 요청 없음
- 라이트/다크 테마 모두 대응 (`prefers-color-scheme` 및 명시적 `data-theme` 지정)
- 한글 폰트는 시스템 스택 사용 (Pretendard → Apple SD Gothic Neo → Noto Sans KR → Malgun Gothic)
- 도해는 인라인 SVG, 표지 나침도는 Canvas
- 모바일(820px 이하)에서는 단일 열 세로 스크롤로 전환

## 수정

내용은 `index.html` 안의 `<section class="slide">` 블록에 순서대로 들어 있습니다.
슬라이드를 추가하려면 같은 형식으로 섹션을 넣기만 하면 됩니다 —
번호, 목차, 진행바 눈금은 `data-part`와 `data-title` 속성을 읽어 자동으로 갱신됩니다.

```html
<section class="slide" data-part="5" data-title="목차에 표시될 제목">
  <div class="eyebrow">Part 05 · 소제목</div>
  <h2 class="t">슬라이드 제목</h2>
  <p class="lead">도입 문장</p>
  <div class="body"> ... </div>
  <div class="note"><b>강의 노트</b>발표자용 메모</div>
</section>
```
